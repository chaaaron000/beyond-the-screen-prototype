# beyond-the-screen-prototype

《화면 너머의 너》 2막 시스템 검증용 웹 프로토타입.

## 목적

- VN 대화 ↔ 보고서/조사 화면 흐름 검증
- 조사에 따른 정보 발견과 조사 후보 변화 검증
- 미라/서윤 병렬 작업과 시간 경과 검증
- 확보한 근거에 따라 같은 의견에 대한 반응이 달라지는 구조 검증

## 에셋 넣는 곳

- `public/assets/characters/` — 한서윤, 미라 스탠딩/표정
- `public/assets/backgrounds/` — VN 배경
- `public/assets/ui/` — 아이콘, 장식, UI 이미지
- `public/assets/evidence/` — 보고서에 띄울 사진/지도/도표

현재는 폴더 구조만 잡아둔 상태입니다.
